Checklist to go live

  1. Download the pack (or copy files from preview)
  2. Create a GitHub repo and push the fixed files
  3. Open Render (free) → New Web Service → connect the repo
  4. If static HTML only: use GitHub Pages or jsDelivr CDN on the raw files
  5. Open the URL Render / Pages gives you
