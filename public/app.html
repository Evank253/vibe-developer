Ship — connect & deploy

How auto-deploy works: You sign in once. VibeDev can push and enable hosting for you.
  • GitHub Pages — paste a GitHub token (repo scope). VibeDev creates/updates a repo, pushes files, turns on Pages.
  • Render — link GitHub inside Render once, then paste a Render API key. VibeDev creates a free web service from your repo.
No product can deploy to your accounts without that one-time link (security).

1. Link GitHub

Create at github.com/settings/tokens · stored only in this browser

2. Deploy target

Dashboard → Account Settings → API Keys · first link your GitHub under Render → Account → GitHub
