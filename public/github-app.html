Make VibeDev a GitHub App

Register once on GitHub. Users then install / sign in on your website — they should never paste tokens into chat.

Option A — GitHub App (recommended)

  1. Go to github.com/settings/apps/new
  2. GitHub App name: VibeDev Fix Ship (or unique name)
  3. Homepage URL: your site (or jsDelivr demo URL for now)
  4. Callback URL: https://YOUR-DOMAIN/app.html
  5. Uncheck Webhook if you do not need events yet (or set a URL later)
  6. Permissions → Repository: Contents (Read & write), Metadata (Read), Pages (Read & write)
  7. Account permissions: Email (optional)
  8. Where can this app be installed? Any account (or Only on this account while testing)
  9. Create → copy Client ID (and generate a client secret if using server OAuth)

Option B — OAuth App (simpler)

  1. Developer settings → OAuth Apps → New
  2. Authorization callback URL: your hosted app.html origin
  3. Copy Client ID into the field below (saved in this browser only)

Save Client ID for this browser

Then open the app and use Sign in with GitHub (Device flow). Client secret stays on a server if you host the full OAuth code exchange.
