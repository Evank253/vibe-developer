VibeDev is a website app that connects to GitHub. Import an existing project, repair it, push it, and deploy — without fighting setup.

Launch Fix & Ship Set up as GitHub App

1. Import

Drop a zip or project files. Not an idea generator — it works on what you already have.

2. Fix

Clean junk, fill missing basics, prepare the tree so hosts accept it.

3. Ship

Connect GitHub → push → enable Pages or hand off to Render.

GitHub App (owner setup)

To make this a real installable GitHub App for your users, register it once on GitHub. Full steps:

  1. Open GitHub App setup
  2. Create the App (or OAuth App) with the listed permissions
  3. Put Client ID on your hosted VibeDev site
  4. Users click Sign in with GitHub — no pasting tokens into chat
